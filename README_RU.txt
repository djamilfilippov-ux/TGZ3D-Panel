TGZ3D Panel — исходный проект Android (Kotlin)

Что есть:
- плавающее окно поверх других приложений;
- перетаскивание за заголовок;
- сворачивание/разворачивание содержимого;
- крестик закрытия;
- кнопка «9999 дерева» с демонстрационным уведомлением.

Важно: кнопка не изменяет игровые ресурсы. Это только демонстрационный интерфейс.

Как собрать APK:
1. Распакуйте архив на компьютере.
2. Установите Android Studio с Android SDK.
3. В Android Studio выберите Open и укажите папку TGZ3D-Panel.
4. Дождитесь Gradle Sync. Если будет предложено установить Android SDK Platform 35, согласитесь.
5. Выберите Build > Build APK(s).
6. APK обычно появится в app/build/outputs/apk/debug/app-debug.apk.
7. Перенесите APK на телефон и установите. Android может попросить разрешить установку приложений из этого источника.
8. Откройте приложение, нажмите «Открыть плавающее окно» и разрешите показ поверх других приложений.

Сборка APK в этой среде не выполнялась: здесь не установлен Android SDK/Gradle. Архив содержит исходный Android Studio проект, а не готовый APK.
